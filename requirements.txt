# Проекту не нужны внешние Python-пакеты.
#
# Всё микширование делает FFmpeg через subprocess, а Python использует только
# стандартную библиотеку (argparse, json, subprocess, pathlib, dataclasses, re,
# math, shutil). Это сделано намеренно:
#
#   * pydub не используется (требование ТЗ);
#   * никаких тяжёлых зависимостей вроде numpy/scipy/librosa;
#   * `pip install -r requirements.txt` проходит без сети.
#
# Внешние требования, которые pip не устанавливает:
#
#   * Python 3.11 или новее;
#   * FFmpeg и ffprobe, доступные в PATH (проверка: ffmpeg -version).
#
# Если позже понадобятся dev-инструменты, добавляйте их сюда с фиксацией версии,
# например:
#   ruff==0.6.9
