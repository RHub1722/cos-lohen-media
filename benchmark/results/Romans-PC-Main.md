## Про GPU

Варианта «на GPU» в бенчмарке нет намеренно: в FFmpeg отсутствуют аудиофильтры с аппаратным ускорением. Проверить на своей сборке:

```bash
ffmpeg -hide_banner -filters | grep -iE "cuda|opencl|vulkan|qsv" | grep -E "A+->A+"
```

Пустой вывод означает, что ни один аудиофильтр GPU не использует. Все методы из `ffmpeg -hwaccels` относятся только к видео.
