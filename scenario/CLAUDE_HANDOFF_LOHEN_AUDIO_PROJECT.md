# Lohen Cosplay Audio Project - Claude Handoff

## 1. Назначение документа

Этот документ является полным техническим заданием для Claude Code по проекту звуковой дорожки к косплей-выступлению Лоэна из Genshin Impact.

Рабочая папка проекта:

```text
C:\Cosplay\audio-project
```

Проект уже мог быть частично создан ранее. Claude должен сначала изучить существующие файлы и текущую архитектуру. Не нужно создавать всё заново, если рабочий код уже существует.

Главная задача:

- собрать сценическую звуковую дорожку длительностью не более 2 минут;
- целевая длительность текущего сценария - 1 минута 43 секунды;
- использовать готовые голоса, атмосферу аукциона, толпу, боевые эффекты и ледяной финал;
- все события разместить по точным таймкодам;
- сохранить возможность быстро передвинуть любой звук после записи хореографии;
- экспортировать общий мастер и отдельные stems.

---

# 2. Общая концепция номера

Лоэн находится на подпольном аукционе. Зрителям сначала кажется, что его выставили как опасное оружие или редкий лот.

Он сидит на стуле, выглядит связанным и полностью спокойным.

Покупатель замечает, что пленник ведёт себя подозрительно спокойно.

Лоэн отвечает с тихой, хитрой насмешкой:

> "I was beginning to think... no one would notice."

После объявления "Sold" Лоэн освобождается и раскрывает ловушку:

> "You misunderstand. I was never the merchandise."

После этого начинается короткая боевая сцена. Толпа впадает в панику. Лоэн уничтожает или обезвреживает противников.

После боя он спокойно спрашивает:

> "Was that all?"

Финальная сцена переходит в холодную ледяную атмосферу.

Последняя реплика:

> "How disappointing."

Затем происходит мощный ледяной удар и номер заканчивается неподвижной финальной позой.

Главный контраст персонажа:

- внешне спокойный и вежливый;
- внутренне хищный и самоуверенный;
- не выглядит испуганным;
- заранее контролирует ситуацию;
- получает удовольствие от риска и превосходства.

# 3. Целевая продолжительность

```text
Общая длительность: 103 секунды
Формат времени: MM:SS.mmm
Начало: 00:00.000
Конец: 01:43.000
```

Не нужно искусственно растягивать выступление до двух минут.

Оптимальный диапазон:

```text
01:35-01:45
```

Текущая версия:

```text
01:43.000
```

# 4. Полный сценический сценарий

## 00:00.000-00:08.000 - появление лота

### Сцена

- Лоэн сидит на стуле.
- Голова опущена.
- Руки находятся за спиной или выглядят связанными.
- Движений почти нет.
- Свет тёмный.
- Зрителю дают несколько секунд рассмотреть костюм.

### Звук

- акустика большого закрытого аукционного зала;
- спокойный приглушённый гул толпы;
- редкие шаги;
- лёгкое движение ткани;
- никаких громких эффектов;
- музыка либо отсутствует, либо используется едва слышимый низкий атмосферный слой.

### LED wall

Предпочтительно:

- тёмный аукционный зал;
- красно-золотые элементы;
- медленный дым;
- слабое движение света;
- без активных персонажей и AMV.

### Звук

- фон толпы немного приглушается под голосом ведущего;
- голос ведущего должен звучать объёмно и официально;
- ведущий может иметь лёгкую реверберацию большого зала.

## 00:57.000-01:20.000 - боевая сцена

Важно:

Текущие таймкоды боя являются техническим черновиком.

Окончательные таймкоды должны быть определены после записи видео реальной хореографии.

Фонограмма должна подстраиваться под исполнителя, а не исполнитель под случайно выбранные звуки.

### Драматургия боя

- толпа сначала осознаёт угрозу;
- начинается паника;
- Лоэн выполняет короткую серию точных движений;
- присутствует один выстрел и уклонение;
- используются разные типы взмахов и попаданий;
- бой не должен выглядеть как бесконечное вращение копья;
- каждый звук связан с конкретным действием;
- к 01:20 бой резко заканчивается.

### Черновая последовательность

assets/crowd/crowd_panic_rise.wav

Паника быстро развивается из шока в реальный страх.

Параметры:

```text
gain: около -18 dB
fade-in: около 100 ms
stereo: широкий
```

Паника должна оставаться позади боевых эффектов.

# 8. Требования к исходным аудиофайлам

Предпочтительный формат:

```text
WAV
48 kHz
16-bit или 24-bit
```

Каналы:

```text
ambience: stereo
crowd: stereo
one-shot SFX: mono или stereo
voices: mono или stereo
```

Не использовать MP3 как источник мастер-файла, если доступен WAV.

Не изменять исходные WAV.

При подготовке:

- можно убрать очевидную тишину в начале и конце;
- нельзя обрезать естественный хвост реверберации;
- добавить fade-in и fade-out 5-20 ms для защиты от щелчков;
- не нормализовать каждый SFX до максимума;
- сохранить динамический диапазон.

# 9. Требования к рендеру

Использовать:

```text
Python 3.11+
FFmpeg
subprocess
JSON timeline
```

Не использовать `pydub`.

Все пути должны быть относительными к корню проекта.

Итог:

```text
Duration: 103.000 seconds
Sample rate: 48000 Hz
Channels: stereo
Codec: PCM 24-bit WAV
Integrated loudness: около -16 LUFS
True Peak: не выше -1.5 dBTP
```

Не допускать клиппинга.

# 10. Иерархия громкости

Приоритет:

```text
1. Голоса
2. Сюжетные акценты
3. Главные попадания
4. Взмахи
5. Реакции толпы
6. Постоянная атмосфера
```

Не делать все эффекты одинаково громкими.

## Ducking

Когда звучит любой голос:

```text
ambience: дополнительно -6 dB
crowd: дополнительно -8 dB
music: дополнительно -6-8 dB
attack: около 80 ms
release: около 300 ms
```

Боевые эффекты приглушать только при реальном конфликте с речью.

Если sidechain в FFmpeg нестабилен, использовать заранее рассчитанную volume automation.

# 11. Зацикливание атмосферы

Не использовать резкое повторение файла.

Длинные фоновые файлы должны повторяться через:

```text
equal-power crossfade
длительность кроссфейда: 300-500 ms
```

Зацикливанию подлежат:

```text
auction_hall_room.wav
auction_crowd_murmur.wav
frozen_hall_ambience.wav
```

Короткие one-shot эффекты не повторять.

# 13. LED wall и визуальная часть

Не использовать полноценный AMV на протяжении всего номера.

Причины:

- он перетягивает внимание с исполнителя;
- создаёт визуальную перегрузку;
- усложняет синхронизацию;
- персонаж на экране может конкурировать с живым выступлением;
- костюм теряется на слишком активном фоне.

Предпочтительный вариант:

## Состояние 1 - аукцион

```text
00:00-00:57
```

- тёмный зал;
- дым;
- красно-золотой свет;
- медленные частицы;
- без активных персонажей.

## Состояние 2 - бой

```text
00:57-01:20
```

- более тёмный и тревожный фон;
- редкие красные вспышки;
- абстрактные линии движения;
- без отдельной аниме-драки.

## Состояние 3 - лёд

```text
01:29-01:43
```

- холодный синий цвет;
- трещины льда;
- снег или кристаллические частицы;
- затем фиксация изображения.

Номер должен работать даже без LED wall.

# 14. Ограничения и риски

## Текущие тайминги боя не окончательные

Они существуют только для технической сборки.

После записи видео хореографии необходимо:

- отметить фактические кадры взмахов;
- отметить фактические моменты попаданий;
- измерить время подъёма со стула;
- проверить длительность разворотов;
- передвинуть SFX;
- не заставлять исполнителя ускоряться ради чернового таймлайна.

## Наушник с командами

Не является основным решением.

Риски:

- задержка Bluetooth;
- выпадение;
- отвлечение;
- заметность;
- зависимость от дополнительного устройства.

Предпочтительно использовать художественные звуковые маркеры как подсказки:

```text
щелчок
удар молотка
выстрел
обрыв музыки
нарастание льда
```

## Не добавлять лишнее

Не использовать без отдельного решения:

- стоны;
- человеческие крики после каждого удара;
- звуки крови;
- слишком частые попадания;
- постоянный громкий визг толпы;
- случайные взрывы;
- автоматическую музыку неизвестного происхождения.

# 15. Проверка перед рендером

Claude должен проверить:

- установлен ли FFmpeg;
- работает ли `ffmpeg -version`;
- существуют ли папки;
- читаются ли WAV;
- фактическую длительность каждого WAV;
- sample rate;
- количество каналов;
- нет ли отрицательных таймкодов;
- не выходит ли событие за 103 секунды;
- нет ли дублирующихся идентификаторов;
- нет ли клиппинга;
- какие ассеты отсутствуют;
- какие файлы имеют подозрительный голос, крик или музыку.

Отсутствующие необязательные файлы не должны останавливать сборку.

Они должны попасть в:

```text
render-report-v2.json
```

6. Записать видео черновой хореографии.

# 19. Критерий готовности

Текущая версия является техническим прототипом.

Она считается готовой для следующего этапа, если:

- все доступные голоса слышны;
- атмосфера аукциона не мешает речи;
- толпа реагирует, но не доминирует;
- боевые эффекты расположены по JSON;
- ледяной переход читается;
- мастер длится ровно 103 секунды;
- нет клиппинга;
- созданы stems;
- любой таймкод можно изменить без переписывания Python-кода.
