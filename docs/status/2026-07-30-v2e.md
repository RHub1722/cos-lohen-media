## 2. Долг по MP3 закрыт для четырёх новых реплик

Формат генерации — `pcm_24000`, то есть **сырой PCM без потерь**. Проверено по
байтам: ни MPEG-фреймов, ни RIFF-заголовка, чистый `s16le`. Полоса урезана до
12 кГц, но артефактов сжатия нет вообще, и §8 для этих файлов выполняется.

Две находки по тарифам, которые стоит запомнить:

* **`pcm_24000` доступен даже на free.** Тариф в документации оговорён только для
  44.1 кГц PCM, который требует Pro. Для речи под фоном зала 24 кГц более чем
  достаточно, так что Pro за $99 проекту не нужен.
* **Free вообще не даёт использовать библиотечные голоса через API** — жёсткий
  `402 paid_plan_required`, символы не списываются. В веб-интерфейсе те же голоса
  работают, поэтому три первые реплики и получились. Оформлен Creator; на нём
  доступ открылся.

Три первые реплики по-прежнему нарезаны из MP3 128 kbps. Теперь их можно
перегенерировать в `pcm_24000` и закрыть долг целиком — вопрос к заказчику,
менять ли уже одобренное звучание.

## 3. Молоток сдвинут: 00:40.500 → 00:41.200

Реплика «Sold» длится 0.959 с и в прежний слот 0.5 с не влезала — удар приходился
на середину слова.

По §4 удар молотка — это **единственный триггер, по которому исполнитель начинает
вставать**. Триггер не должен ни с чем совпадать: если он звучит внутри слова,
момент приходится угадывать. Время молотка в ТЗ помечено как ориентировочное,
поэтому сдвинут он, а не голос.

```text
00:40.000  «Sold» начинается
00:40.990  «Sold» закончился
00:41.200  удар молотка      ← пауза 0.21 с, удар в тишине
```

Заодно это правдоподобнее: аукционист говорит «Sold», потом бьёт молотком.

Если 0.21 с на слух покажется тесно, добавить 100 мс — правка одного поля.

## 4. Пауза в `lohen_reveal` расширена: 0.67 → 1.27 с

По §4 действия привязаны к словам внутри второй фразы: на «never» видно, что
Лоэн не пленник, на «merchandise» он достаёт оружие. Это самая сложная
синхронизация в номере.

Пауза между фразами расширена вставкой тишины, чтобы вторая фраза начиналась
после отчётливого провала:

```text
00:48.000  «You misunderstand»
00:51.018  «I was never the merchandise» — чистый старт
00:52.700  конец слова «merchandise» → боевая стойка
```

Больше секунды на освобождение рук, и выходить движением нужно на конец фразы, а
не попадать внутрь неё. Расширение сделано в файле проекта; оригинал в `raw/`
сохранил исходную паузу.
