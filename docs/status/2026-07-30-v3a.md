## 1. Что изменилось по вводным

Заказчик передал сценарий команде, и оттуда пришли два ограничения, которых в ТЗ не было:

- **выступление максимум 1 минута** на человека (в прошлом году было 1:30);
- **нельзя показывать насилие**, в частности бить участника по-настоящему. Списка правил у организаторов нет.

Уточнено отдельно: минута — это длина **дорожки**, не всё время на сцене.

Сроки: **аудиофайл сдавать через неделю** от 2026-07-30, ивент через месяц.

### Следствие из сроков, которое переворачивает подход

Аудио замерзает через неделю, хореография ставится ещё три недели после. По §18 ТЗ шли наоборот — сначала снять черновую хореографию, потом подогнать боевые таймкоды. Теперь подгонять придётся исполнителя под трек.

Отсюда принцип нарезки: **каждое движение начинается от слышимого триггера.** Движение, которое не на что повесить, на репетициях не сойдётся, а исправлять будет уже нечем.

## 2. Скачивание трейлера

Запрет ТЗ «не скачивать никакие материалы из интернета» **снят заказчиком для одного файла** — звука трейлера. Заодно снят запрет на редактирование ТЗ. Оба снятия зафиксированы здесь, потому что в §13 разбора они всё ещё перечислены как действующие.

Файлы лежат в `assets/trailer/` и **закрыты от git**: чужой материал, и 50 МБ WAV в истории не нужны. Воспроизводятся так:

```bash
python -m pip install --user yt-dlp
```
```bash
python -m yt_dlp -f bestaudio -o "assets/trailer/lohen_trailer_source.%(ext)s" "https://www.youtube.com/watch?v=PYA-iyy2fxA"
```
```bash
ffmpeg -y -i assets/trailer/lohen_trailer_source.webm -af "aformat=sample_fmts=s32:sample_rates=48000:channel_layouts=stereo" -c:a pcm_s24le assets/trailer/lohen_trailer_full.wav
```

Субтитры — официальная английская дорожка, ручная, не авто-распознавание:

```bash
python -m yt_dlp --skip-download --write-subs --sub-langs "en.*" --sub-format vtt
```

## 3. Замеры, на которых стоит сценарий

Все цифры получены измерением, не чтением субтитров.

### 3.1. Обрыв речи в звуке не виден

Разбор ставил обрыв на 1:39.5. По субтитрам реплика с недоконченным словом идёт **1:38.406–1:40.356**, следующая — только **2:10.071**, то есть бессловесный отрезок **29.7 с**. Это подтвердилось.

Но по огибающей на 93–102 с уровень держится около −16 dB **без единого провала**. Речь там прерывается, музыка продолжается, и по уровню момент не поймать. Значит точность до миллисекунды здесь недостижима и не нужна: триггер для исполнителя слуховой — голос давится на середине слова, это слышно безошибочно.

### 3.2. Настоящая тишина найдена, и она лучше

| Время | Уровень |
|---|---|
| 104.82 | −10.7 dB |
| 104.86 | −20.2 dB — обрыв начинается |
| 104.94 | −39.3 dB |
| **105.02** | **−46.2 dB — дно** |
| 105.18 | −39.0 dB |
| 105.74 | −7.2 dB — полный уровень вернулся |

Падение с −10 до −46 dB за 0.15 с. Это не фейд, а жёсткая склейка самого трейлера. **Точка реза выбрана 105.05.**

Главное: такая тишина — точка склейки **в обе стороны.** Её можно не только использовать как шов, но и растянуть, вставив свой материал. Именно это и сделано в блоке 2 сценария.

### 3.3. Боевой отрезок — стена без акцентов

Отрезок 105.45–132.5, шаг 200 мс:

| | |
|---|---|
| Медиана | −10.9 dB |
| Разброс | 10.5 dB |
| В пределах ±3 dB от медианы | **96% времени** |

За 27 секунд ни одного всплеска: ни удара, ни ледяного треска. Плотно сжатая непрерывная музыка, LRA всего 5.4 LU.

Вывод: **под трейлерную боевую музыку нельзя ставить движения** — вешать их не на что. Но как фон она хороша: плоской подложке не с чем спорить, и её можно приглушать под нашими ударами. Поэтому акценты кладём мы, а музыка остаётся трейлерной.

Первый детектор акцентов дал ложный результат — выдал события ровной сеткой через 0.26 с. Он требовал роста от локального максимума, а в стене звука локальный максимум и так высок, поэтому сработал на каждом окне. Правильный ответ дала не эвристика, а просмотр огибающей сеткой.

### 3.4. Громкость аукционной половины

Отрезок 67.20–105.05:

| | |
|---|---|
| Громкость | **−11.4 LUFS** |
| True Peak | **+0.2 dBTP** — за полной шкалой |
| LRA | 5.4 LU |
| Пик / RMS | 0.000 / −14.38 dBFS, crest 14.38 dB |

Трейлерную половину придётся **приглушать примерно на 4.6 dB**, а не поднимать. Вся нормализация проекта строилась под слишком тихий черновик: v2 просил +7.75 и получил +6.98. Теперь знак меняется.

### 3.5. Код нормализации к этому готов

Проверено чтением: оба ограничителя в `src/renderer.py` срабатывают только на `requested_gain > X` — `preserve_dynamics` на строке 1146, `max_normalize_gain_db` на 1158. Отрицательный прирост проходит мимо обоих, и слишком громкий микс нормализуется ровно до −16 LUFS. `preserve_dynamics` вдобавок сам поднимает целевой LRA выше измеренного, так что в динамический режим микс не уедет.

**Менять код сборки не нужно.**

## 4. Структура v3

Трейлерная дорожка идёт двумя кусками: **A** = 1:07.20–1:45.05, **B** = 1:45.45 и далее. Между ними наша вставка в тишине.

| Блок | Наше время | Звук |
|---|---|---|
| 1. Аукцион | 00:00.0–00:37.85 | трейлер, кусок A |
| 2. Тишина и раскрытие | 00:37.85–00:43.60 | только наша реплика |
| 3. Бой | 00:43.60–00:49.60 | трейлер, кусок B + наши удары |
| 4. Лёд | 00:49.60–01:00.00 | только наше |

Ключевые точки:

| Время | Что | Триггер для исполнителя |
|---|---|---|
| 00:04.1 | молоток, продан **другой** лот | нет реакции |
| **00:13.5** | объявление главного лота | **ткань падает** |
| 00:15.0–00:31.2 | описание лота | стоит раскрытым, неподвижно |
| **00:31.2** | ведущий давится на слове | **поднимает голову, берёт копьё** |
| 00:37.85 | тишина −46 dB | стоит |
| 00:38.45 | «I was never the merchandise» | реплика в полной тишине |
| **00:43.60** | музыка врывается | **движение копьём** |
| 00:46.30 | удар по броне | низкий выпад |
| **00:49.60** | ледяной разряд, **музыка обрывается за 0.25 с** | **копьё в пол** |
| 00:50.80 | «Was that all?» | канонная поза: кисть раскрыта и опущена |
| 00:53.30 | «How disappointing.» | неподвижно |
| 00:55.50 | ледяной удар | финальная поза, 4.5 с |

Семь движений на минуту, каждое от слышимого триггера. Промежутки 2.7 / 2.2 / 1.1 / 5.9 с.

Музыка умирает **на ударе копья в пол** — это переворот палитры из разбора (красный в льдисто-белый), только слышимый. Заодно решается разборчивость: обе финальные реплики идут в тишине, а не сквозь стену в −11 dB.

### Поправка по накидке

Первая версия структуры держала ткань до обрыва речи — **31.2 с из 60, то есть 52% номера.** Заказчик возразил, и возражение верное: на косплей-конвенции костюм и есть заявка, прятать его больше половины выступления — работать против себя.

Сброс перенесён на объявление главного лота:

| | Было | Стало |
|---|---|---|
| Под тканью | 31.2 с (52%) | **13.5 с (22%)** |
| Костюм виден | 28.8 с | **46.5 с (78%)** |

Получилось не компромиссом, а улучшением: описание лота теперь идёт **на видимый костюм**, а не на простыню, и у судей появляется 17 секунд, когда костюм просто стоит и его можно рассматривать.

Ткань не стягивается руками, а **отпускается**: груз по кромке тянет её вниз и назад. Если стягивать, зал увидит движущегося человека, и смысл «экспонат был жив всё время» не сработает.

### Что важно не забыть при сборке

Наша половина должна **начинаться громко**. Зритель уходит со стены в −10.9 dB, и если просто подогнать интегральную громкость, наши 22 с прозвучат как сдувшийся шарик. Первый удар после шва встаёт на самый верх иерархии.
