# Точки состояния проекта

Каждая точка — снимок проекта на конкретный момент: что готово, что
отсутствует, что перепроверить. Точки не переписываются: при новой сборке
создаётся новый файл, старые остаются как история решений.

## Соглашение об именах

```text
docs/status/YYYY-MM-DD-<версия сборки>.md
```

Версия сборки — суффикс, с которым собран мастер (`v2` для `master_v2.wav`).
Если за один день делается несколько точек по одной версии, добавляется буква:
`2026-07-29-v2b.md`.

## Как пользоваться

Перед новой сборкой прочитать последнюю точку — там список того, что нужно
перепроверить, с ожидаемым результатом по каждому пункту. После сборки создать
новую точку и дописать строку в таблицу выше.
